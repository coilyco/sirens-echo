# Sirens community knowledge

* Sirens Echo is the automated community host.
* `#bots` is the isolated channel where members can summon Sirens Echo during
  the initial rollout.
* The Sirens community operates game servers. Eco is the currently documented
  game in this repository.
* This initial skillpack contains no event schedule, staff directory,
  moderation policy, account policy, or authoritative gameplay guide.
