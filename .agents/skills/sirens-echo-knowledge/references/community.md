# Sirens community knowledge

* `#bots` is the isolated channel for direct Sirens Echo requests during the
  initial Discord rollout.
* The Sirens community operates game servers. **Which game this deployment
  answers for is named by its game focus root**, not here, so that a swap does
  not need this file edited.
* This initial skillpack contains no event schedule, staff directory,
  moderation policy, account policy, or authoritative gameplay guide.
