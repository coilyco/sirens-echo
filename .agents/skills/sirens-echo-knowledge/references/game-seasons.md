# Game seasons

**Applies to** any question about whether a game is running, when it returns, or why the focus is the game it is. Not a bound on the focused game's own mechanics, which its focus root carries.

The community runs more than one game and answers for one at a time, which the
game focus names. **This file says which games are running, and it is the only
game-neutral file that may name a game.** A game's mechanics, links, and server
rules stay in that game's own focus root, because those are what a swap must
carry away and this is what a swap must leave behind.

* **The community runs servers for more than one game.** Channels existed for
  Eco, Satisfactory, Icarus, Prosperous Universe, Factorio, and Vintage Story
  when this was observed on 2026-09-12. A channel is not proof a server is
  running, and the live channel list is the authority.
* **Enshrouded is running**, on a world from 2026-09-12 that runs no cycle.
* **Eco is in season: cycle 15 opened 2026-10-09** on Eco 0.14.2.0, modlist 23 kept,
  7 benched. Live questions answer from the world through the eco tools.

**Enshrouded's line is from 2026-09-12.** Re-check it against the live channel list.
